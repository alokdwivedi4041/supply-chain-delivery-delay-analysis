# 📦 Supply Chain & Delivery Delay Analysis

End-to-end data analytics project that finds **why deliveries are late, which carriers/regions/seasons cause it, and how much revenue it puts at risk**, using Python, SQL and statistics, with a delay-prediction model on top.

> **Data note:** The dataset is **synthetic** (6,000 e-commerce orders across 17 Indian cities, 5 carriers, 4 warehouses, year 2024), generated by `src/generate_data.py` with realistic patterns and deliberate data-quality problems (duplicates, missing values, inconsistent text, outliers). The pipeline works the same on any real orders dataset, such as the Kaggle *DataCo Smart Supply Chain* data.

## 🎯 Business Problem
An e-commerce company is losing customer satisfaction and revenue to late deliveries. Leadership wants to know: **How bad is it, where is it coming from, and what should we fix first?**

## 🧰 Tech Stack
Python (Pandas, NumPy) · SQL (SQLite, window functions, CTEs) · Matplotlib / Seaborn · SciPy (chi-square tests) · scikit-learn (logistic regression)

## 🔄 Workflow
1. **Generate / ingest** raw orders data (`src/generate_data.py`)
2. **Clean**: remove duplicates, fix text casing/whitespace, drop invalid values, impute missing, cap outliers (`src/clean_data.py`)
3. **Feature engineering**: delay_days, is_delayed, season, distance band, delay severity, revenue at risk
4. **SQL analysis**: 8 business queries using `RANK`, `LAG`, running totals (`sql/queries.sql`)
5. **EDA + visuals**: 8 charts (`src/analysis.py`)
6. **Statistical testing**: chi-square tests for each driver
7. **Predictive model**: logistic regression to flag high-risk orders
8. **Recommendations** (`reports/insights.md`)

## 📊 Headline Results
| Metric | Value |
|---|---|
| Orders analysed (after cleaning) | 5,992 |
| Overall delay rate | **41.1%** |
| Average delay when late | 2.69 days |
| Order value tied to delayed shipments | **₹89.5 lakh (40.9%)** |
| Avg rating: on-time vs delayed | 4.49 → **3.45** |
| Delay-prediction model ROC-AUC | 0.69 |

## 🔍 Key Insights
1. **Carrier is the biggest driver.** QuickKart Logistics is late **60.7%** of the time vs **29.2%** for SwiftShip (chi-square p < 0.001).
2. **Seasonality:** Festive season (Oct–Nov) delay rate is **49.8%** vs 37.5% in winter; October peaks at **52%**. Monsoon months also spike.
3. **East region is the weakest (50.3%)**; the QuickKart × East lane hits **73%**, and Guwahati lanes reach 77–83%.
4. **Root causes:** Carrier Capacity, Warehouse Dispatch Delay and Weather together explain **58%** of all delays, and the first two are controllable.
5. **Customer impact:** a 3+ day delay drops average rating to **2.74** vs 4.49 for on-time orders.

## ✅ Recommendations
- Shift volume away from the worst carriers on East-region lanes, or enforce SLA penalties.
- Add buffer capacity and pre-position stock before monsoon and festive peaks.
- Fix warehouse dispatch backlogs (internal and controllable).
- Use the delay-risk model to trigger proactive customer messages on high-risk orders.

## ⚠️ Limitations & Next Steps
- Data is synthetic, so findings demonstrate the method rather than a real company's performance.
- Model is a simple baseline (AUC 0.69); next steps: gradient boosting, weather/traffic features, SHAP.
- Build a Power BI / Tableau dashboard on `orders_clean.csv`.
